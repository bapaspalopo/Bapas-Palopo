# Bapas Palopo — Link Hub

Portal tautan resmi Bapas Kelas II Palopo.

## Struktur
- `index.html` — halaman publik
- `data/profile.json` — data profil, layanan, kontak, dan tautan
- `admin/` — editor visual
- `.github/workflows/publish-linkhub.yml` — workflow publish dari admin

## GitHub Pages
Aktifkan **Settings → Pages → Deploy from a branch → main / root** jika plan repository mendukung GitHub Pages.

## Admin
Buka `/admin/`. Editor akan membuat permintaan publish melalui GitHub Issues. Workflow hanya menerima permintaan yang dibuat oleh akun **bapaspalopo**.
